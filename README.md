# Визуализатор графа зависимостей

## Общее описание

Консольный инструмент на Go для визуализации графа зависимостей
пакета. Готовые менеджеры пакетов и библиотеки для получения
зависимостей не используются. Единственная внешняя библиотека —
`github.com/BurntSushi/toml` для чтения конфигурации.

Этап 1: минимальный прототип. Инструмент читает конфигурационный
файл TOML, проверяет все параметры и выводит их в формате
«ключ: значение». При ошибке в любом параметре выводится понятное
сообщение, а программа завершается с ненулевым кодом.

## Структура проекта

* `main.go` — точка входа, разбор командной строки;
* `internal/config/config.go` — структура `Config`, чтение TOML,
  вывод параметров;
* `internal/config/validate.go` — проверка значений параметров;
* `internal/config/errors.go` — типы ошибок конфигурации;
* `internal/config/*_test.go` — модульные тесты;
* `config.toml` — конфигурационный файл по умолчанию;
* `tests/` — конфигурации и `.bat`-сценарии для демонстрации;
* `run.bat` — запуск в Windows;
* `.gitignore`, `.gitattributes`, `go.mod`.

## Параметры конфигурации

Все параметры обязательны.

| Ключ | Тип | Описание | Проверка |
|------|-----|----------|----------|
| `package_name` | строка | имя анализируемого пакета | не пустое, до 214 символов, допустимы буквы, цифры и символы `@ . _ / : + -` |
| `repository` | строка | URL репозитория или путь к файлу тестового репозитория | зависит от `repository_mode` |
| `repository_mode` | строка | режим работы с репозиторием | `"remote"` или `"test"` |
| `version` | строка | версия пакета | не пустая, до 128 символов, формат вида `1.3.0`, `2.0.0-beta.1` |
| `ascii_tree` | bool | вывод зависимостей в виде ASCII-дерева | `true` или `false` |
| `max_depth` | целое | максимальная глубина анализа | от 1 до 100 |

Режимы `repository_mode`:

* `remote` — `repository` это URL, схема `http` или `https`, адрес
  должен содержать хост;
* `test` — `repository` это путь к существующему файлу тестового
  репозитория (относительные пути считаются от текущего каталога).

Пример `config.toml`:

```toml
package_name = "left-pad"
repository = "https://registry.npmjs.org"
repository_mode = "remote"
version = "1.3.0"
ascii_tree = true
max_depth = 3
```

## Запуск

Перед первым запуском нужно скачать зависимость и создать
`go.sum`:

```bat
go mod tidy
```

Запуск:

```bat
run.bat
go run . --config config.toml
go run . -h
```

Если параметр `--config` не указан, используется `config.toml`
в текущем каталоге.

Вывод при корректной конфигурации:

```text
package_name: left-pad
repository: https://registry.npmjs.org
repository_mode: remote
version: 1.3.0
ascii_tree: true
max_depth: 3
```

## Обработка ошибок

Программа находит и показывает сразу все проблемы файла:

```text
error: invalid configuration:
  - package_name: contains invalid characters: "bad name!"
  - repository: URL scheme must be http or https, got "ftp"
  - version: invalid version format: "v 1.0"
  - max_depth: must be at least 1, got 0
```

Коды завершения: `0` — успех, `1` — ошибка конфигурации,
`2` — неверные аргументы командной строки.

Виды ошибок:

* файл конфигурации не найден;
* синтаксическая ошибка TOML;
* неверный тип значения (`max_depth = "ten"`, `ascii_tree = "yes"`,
  `package_name = 42`);
* пропущенный обязательный параметр;
* неизвестный параметр (например, опечатка в имени ключа);
* недопустимое значение каждого из параметров (см. таблицу);
* неверный URL, отсутствующий файл или каталог вместо файла
  тестового репозитория;
* лишние аргументы командной строки.

## Тестирование

Модульные тесты:

```bat
go test ./...
```

Сценарии демонстрации запускаются из корня репозитория:

| Сценарий | Что показывает |
|----------|----------------|
| `tests\test_valid.bat` | корректные конфигурации: режимы `remote` и `test`, конфигурация по умолчанию |
| `tests\test_invalid_values.bat` | неверные имя, URL, версия, глубина, режим; отсутствующий файл и каталог вместо файла тестового репозитория |
| `tests\test_missing.bat` | файл без параметров, отсутствующий файл конфигурации, лишний аргумент |
| `tests\test_types.bat` | значения неверного типа |
| `tests\test_syntax.bat` | синтаксическая ошибка TOML и неизвестный параметр |
